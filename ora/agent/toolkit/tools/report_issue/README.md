# report_issue

Append a nonblank message, with its kind (`defect`, the default, or `confusion`:
the policy is unsure what the task, a tool or the instructions mean), through the fixed episode-control writer and return
the released success/error envelope. No physical action or official verdict.
The issue evidence retains the existing round-reset lifecycle and may be read
by finish/abort admission. Replay compares the control request, never writes
the source run. This is explicit episode evidence, not hidden tool-instance state.
